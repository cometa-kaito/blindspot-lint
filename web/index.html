なぜこの5項目なのか

6モデル・30欠陥・1080件の測定から、ローカルLLMの検出率が低い欠陥を特定し、そのうち構文木で決定的に判定できるものに限っています。「検出率」はコードレビューを指示したときにその欠陥を指摘した割合です。

規則見つけるものローカルLLMの検出率既存リンターとの関係
BS001引数のリストを破壊的に並べ替える・消す0%ruff・pylint・bandit は拾わない
BS002浮動小数点の計算結果を == で比べる0%ruff RUF069（preview）と一部重複
BS003値の比較に is を使う0%リテラル比較は ruff F632 が既定で拾う
BS004正規表現の入れ子量化子（ReDoS）2%ruff・pylint・bandit は拾わない
BS005解放されない場所に無制限に貯め続ける0%ruff・pylint・bandit は拾わない

この検査器だけでは足りません

見るのは上の5項目だけです。未定義の名前や文法の誤りは見ません。実測では、この検査器の指摘どおりに直したモデルが必要な import を落とし、実行できないコードを返す事例が出ました。必ず併用してください。
